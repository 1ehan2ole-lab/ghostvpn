# Contributing to GhostVPN

Спасибо за интерес к проекту! Правила простые:

## Как участвовать

1. Форкните репозиторий и создайте ветку от `main`: `git checkout -b feature/my-feature`.
2. Внесите изменения, добавив понятные коммиты на русском или английском.
3. Убедитесь, что тесты проходят: `npm test`.
4. Откройте Pull Request с описанием изменений.

## Требования к коду

- Стиль — как в существующем коде: 2 пробела, одинарные кавычки, `const`/`let`.
- Комментарии и тексты интерфейса — на русском (UI) / английском (код).
- Любая новая функция API должна быть покрыта тестом в `test/`.
- Не коммитьте `data/`, `.env`, `vendor/` — они в `.gitignore`.

## Безопасность

Не публикуйте обнаруженные уязвимости в публичных issue — пишите в приватный канал
(см. [SECURITY.md](SECURITY.md)).
