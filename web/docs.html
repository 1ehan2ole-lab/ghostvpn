Документация

Установка, настройка и эксплуатация собственного VPN на сервере.

1. Требования

  • VPS: Ubuntu 22.04 / Debian 12 (1 vCPU, 1 ГБ RAM достаточно)
  • Публичный IP-адрес и открытые порты 443 и 80
  • Node.js 22+ и root-доступ для установки Xray

2. Установка

git clone https://github.com/1ehan2ole-lab/ghostvpn.git
cd ghostvpn
cp .env.example .env
npm install
npm run xray:install
npm start

При первом запуске панель создаст администратора и напечатает его пароль в консоль. Данные можно задать заранее в .env (ADMIN_EMAIL, ADMIN_PASSWORD).

3. Reverse proxy

server {
    listen 443 ssl http2;
    server_name vpn.example.com;

    ssl_certificate     /etc/letsencrypt/live/vpn.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/vpn.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

В .env укажите PUBLIC_URL=https://vpn.example.com и TRUST_PROXY=1.

4. Docker

git clone https://github.com/1ehan2ole-lab/ghostvpn.git
cd ghostvpn
cp .env.example .env
docker compose up -d
docker compose logs -f

Образ собирает Xray и панель в одном контейнере, порт VPN пробрасывается через network_mode: host.

5. Команды

npm start            # запустить панель
npm run dev          # режим разработки
npm run xray:install # скачать ядро Xray
npm run xray:restart # перезапустить Xray
npm test             # тесты

6. Структура

server/     бэкенд (Express + SQLite)
  routes/    API: auth, me, admin, sub
  xray.js    управление ядром и статистика
web/        статический сайт и кабинеты
scripts/    установка Xray, служебные утилиты
data/       база, конфиг Xray, логи (в .gitignore)

7. Частые проблемы

Клиент не подключается

Проверьте, что порт из настроек открыт на файрволе, SNI совпадает с destination, а ключ REALITY не перевыпускался после генерации конфига.

Трафик не считается

Ядро Xray должно быть запущено с включённым API (127.0.0.1:10085). Счётчики обновляются каждые 30 секунд.

Не открывается порт 443

На Windows и Linux для привязки к порту 443 нужны права root/администратора.
